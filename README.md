# Moneta

Приложение для учёта личных финансов. React 19 + Vite, русский интерфейс, валюта — тенге. Начальное состояние пустое. Демоданные загружаются только по отдельной кнопке.

## Запуск

Нужен Node.js 22.12+ и pnpm 11.25.0.

```sh
pnpm install
pnpm dev
```

Открыть адрес, указанный Vite (обычно http://127.0.0.1:5173).

```sh
pnpm test       # Проверки расчётов и валидации
pnpm build      # Готовый статический сайт в dist/
pnpm preview    # Локальный просмотр собранного сайта
```

Папку `dist` можно разместить на любом статическом хостинге. Сервер приложения и база данных не нужны. Не открывайте `index.html` двойным щелчком: приложение необходимо запускать через HTTP.

## Что можно проверить

- Главная: общий баланс, показатели выбранного месяца, расходы по категориям, пять последних записей, динамика за шесть месяцев и предстоящие операции.
- Форма дохода и расхода: категория, дата, комментарий, проверки суммы и обязательных полей.
- История: поиск, фильтры по типу, категории и периоду, редактирование и удаление с подтверждением.
- Аналитика: распределение расходов, самая большая категория и сравнение доходов с расходами.
- Начальный баланс при первом запуске и в настройках.
- Светлая и тёмная темы, мобильная навигация.
- Экспорт и восстановление JSON с подтверждением замены истории.

## Правила расчёта

Суммы хранятся целым числом тиынов. Допустимо от 0,01 до 999 999 999,99 ₸ на операцию. Начальный баланс может быть нулевым; отрицательный начальный баланс в этой версии не предусмотрен.

Общий баланс — начальный остаток плюс все доходы минус все расходы до сегодняшней даты включительно. Будущие операции отмечаются «Запланировано» и не влияют на баланс, графики и месячные показатели до наступления даты. Месяц на главной по умолчанию текущий; его можно менять для просмотра истории. Период графика — выбранный месяц и пять предшествующих. Дата определяется по локальным часам устройства, проверяется каждые 15 секунд и при возврате в окно. Автоматический переход на новый месяц работает, пока пользователь не выбрал исторический период.

## Хранение и ограничения

Данные находятся в LocalStorage этого браузера, ключ `moneta.finances.v1`. Нет регистрации, сервера, синхронизации между устройствами и банковских интеграций. Очистка данных браузера удаляет историю. Данные на разных адресах сайта (в том числе localhost и размещённая версия) независимы; для переноса есть JSON.

Если сохранение не удалось, приложение показывает ошибку и не выдаёт операцию за сохранённую. Повреждённые ранее сохранённые данные автоматически не перезаписываются. Для восстановления предусмотрен импорт корректной копии.

Шрифт Manrope загружается с Google Fonts; без сети используется системный шрифт.

## Статус

Дизайн согласован. Результаты приёмочных проверок описаны в `docs/ACCEPTANCE.md`.

Для воспроизведения смены даты при локальном запуске откройте `/tests/acceptance.html` на отдельном порту: `pnpm dev --port 5175 --strictPort`. Это то же приложение с управляемыми тестовыми часами. Кнопки дат меняют только часы стенда; обновление баланса выполняет обычный 15-секундный таймер приложения. Файлы стенда не входят в `dist`, в опубликованном приложении нет переключателя даты. Для обычной работы используется дата устройства.
